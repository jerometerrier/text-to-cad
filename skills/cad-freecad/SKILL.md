# FreeCAD parametric parts

Provenance: maintained in [earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad).
Use the installed local skill files as the runtime source of truth.

This skill writes a FreeCAD Python model, runs it in FreeCAD's console
(`freecadcmd`) and saves an `.FCStd` whose model tree is the design history:
a `Params` spreadsheet, sketches attached to origin planes, then Pad, Pocket,
Fillet... A person opens it in FreeCAD, edits a parameter or a sketch, and
the part regenerates. A STEP export goes alongside for the other skills.

Use `$cad` instead when the user only needs a STEP/mesh solid and no
FreeCAD history.

## Setup

Requires FreeCAD 1.0 or newer. `scripts/fcbuild.py` (standard-library
Python 3.9+, paths here are relative to this skill's directory) finds
`freecadcmd` via `--freecadcmd`, `$FREECADCMD`, PATH, then the usual
install folders. Check it first:

```bash
python scripts/fcbuild.py --doctor
```

Exit 2 means FreeCAD was not found: ask the user to install it (FreeCAD
download page, or `conda install -c conda-forge freecad`) or to point
`FREECADCMD` at `freecadcmd`. Do not fall back to another kernel silently.

## Model contract

A model is a Python file that defines `build(doc)`, builds the tree in `doc`
and returns the Body (or a list of Bodies) to export. It runs inside
FreeCAD's Python, where `import fcad` gives the helpers in
`scripts/fcad.py`. [examples/drilled_plate.py](examples/drilled_plate.py)
is the reference model:

```python
import fcad


def build(doc):
    P = fcad.params(doc, length=80.0, width=50.0, thickness=8.0,
                    hole_d=6.5, hole_inset=10.0, corner_r=6.0)
    body = fcad.body(doc, "Plate")

    outline = fcad.sketch(body, "XY", name="OutlineSketch")
    fcad.rectangle(outline, P.length, P.width)
    plate = fcad.pad(body, outline, P.thickness, name="PlatePad")

    holes = fcad.sketch(body, "XY", name="HolesSketch")
    dx, dy = P.length / 2 - P.hole_inset, P.width / 2 - P.hole_inset
    for sx, sy in ((1, 1), (-1, 1), (-1, -1), (1, -1)):
        fcad.circle(holes, P.hole_d, center=(dx * sx, dy * sy))
    drilled = fcad.pocket(body, holes, through_all=True, symmetric=True, name="HolesPocket")

    corners = fcad.edges(drilled, parallel="Z", between_planar_faces=True)
    fcad.fillet(body, drilled, corners, P.corner_r, name="CornerFillet")
    return body
```

Build it:

```bash
python scripts/fcbuild.py src/plate.py --out-dir out --formats step,stl
python scripts/fcbuild.py src/plate.py --out-dir out --set length=120 --name plate_120
```

Outputs are `<out-dir>/<stem>.FCStd` always, plus `.step`/`.stl` only when every
check passes. `--set` overrides a `params()` default for one build.

## Modeling rules

- **Parameters first.** Put every meaningful dimension in `fcad.params()`
  and pass the `Param`s to the helpers: they bind each constraint and
  feature length to the spreadsheet with an expression, so the user edits
  dimensions in one place. `Param`s combine with `+ - * /` and stay bound.
  Name them in words (`thickness`, not `t`): unit symbols are reserved aliases.
- **Attach sketches to the Body's origin planes** (`fcad.sketch(body, "XY",
  offset=...)`), never to a face of an earlier feature. Face and edge names
  are generated by the kernel and change when earlier features change
  (topological naming); the build warns on a sketch attached to generated
  topology.
- **Fully constrain every sketch.** The build fails on any degree of freedom
  left, unless `--allow-underconstrained`. `fcad.rectangle` and `fcad.circle`
  add complete constraint sets; for other profiles read
  [sketch constraints](references/sketch-constraints.md) before writing
  them.
- **Pick fillet and chamfer edges by geometry** with `fcad.edges(feature,
  parallel=..., at_z=...)`, never by typing `"Edge7"`. Prefer rounding a
  corner in the sketch (arc + tangency) when it belongs to a profile.
- **Through-cuts from a base plane**: `pocket(..., through_all=True,
  symmetric=True)` cuts both ways, so it does not depend on which side the
  material is.
- One Body is one solid. Several parts mean several Bodies, returned as a list.
- Millimetres, Z up, a functional datum at the origin unless the user says otherwise.
- The raw FreeCAD API (`body.newObject("PartDesign::Revolution", ...)`,
  datum planes, `PartDesign::Hole`, patterns) is available in the model for
  what the helpers do not cover; keep the same rules.

## Verify

`fcbuild.py` prints one JSON report and exits 0 only when every check passed:

- each sketch: `solve() == 0`, no conflicting, redundant or malformed
  constraints, zero degrees of freedom;
- every document object recomputes without error;
- each returned Body: valid shape (`shape.isValid()`), exactly one solid,
  positive volume;
- the report lists the tree (`bodies[].features`, with their spreadsheet
  bindings), `params`, `volume` and `bbox`.

Read the report, not just the exit code: compare `bbox` and `volume` with the
requested dimensions (compute the expected volume when it is simple). On
exit 1, fix the model from `errors` (constraint numbers are 1-based, as in
FreeCAD's constraint list) and rebuild; the saved `.FCStd` is kept so the
user can inspect a failure in FreeCAD.

For visual review, snapshot or show the exported STEP with `$cad` (its
"Verify and hand off" and "Show the model" sections). For printability,
manufacturing or drawings, hand the STEP/STL to `$dfam-check`, `$dfm`,
`$engineering-drawing` or `$gcode`.

## Hand off

Give the `.FCStd` path first (the editable part), then the STEP/STL, the
parameter names the user can change, the checks that ran and any
assumptions. Mention that the tree opens in FreeCAD's PartDesign workbench
and regenerates when `Params` is edited.
